## NOTES DE PRODUCTION

### Style visuel
- Palette : noir profond (#07070F), orange (#FF6B1A), violet (#9B2FFF), rose (#FF2D78)
- Inspiration : Spider-Verse · Jet Set Radio · GTA V trailer
- Transitions : coupes sèches + glitch effects + motion blur

### Audio
- Genre : Urban / Trap / Electronic
- BPM : 140-160
- Sections : build-up (0-22s) → drop (22-38s) → breakdown Pi (38-46s) → montage final (46-54s) → silence logo (54-60s)

### Versions à produire
| Version | Format | Durée | Usage |
|---------|--------|-------|-------|
| Full | 16:9 | 60s | YouTube |
| Short | 9:16 | 30s | TikTok / Reels |
| Teaser | 9:16 | 15s | Stories |
| Loop | Carré | 8s | Bannière web |

### Outils recommandés
- **Animation** : Unity Cinemachine + Timeline
- **Montage** : DaVinci Resolve (gratuit)
- **Motion Graphics** : After Effects / CapCut Pro
- **Musique** : Splice / Epidemic Sound (license YouTube)
- **Voix off** : ElevenLabs (si narration souhaitée)
